# 📱 Flutter Supabase App

## Description

Ce projet est une **application mobile développée en Flutter**, connectée à **Supabase**. Il propose un **système complet d'authentification** (connexion et inscription), ainsi qu'une **fonctionnalité d'upload de fichiers** après authentification.

Le projet a été réalisé dans le cadre d’un projet scolaire à deux personnes.

## 🔧 Fonctionnalités

- ✅ Authentification avec Supabase (connexion et inscription)
- ☁️ Upload de fichiers pour les utilisateurs connectés
- 📱 Interface simple et responsive

## 🛠️ Technologies utilisées

- [Flutter](https://flutter.dev/) – Framework de développement mobile
- [Dart](https://dart.dev/) – Langage utilisé avec Flutter
- [Supabase](https://supabase.com/) – Backend-as-a-Service (authentification + stockage de fichiers)


## 🚀 Installation

1. **Cloner le projet :**

   git clone https://github.com/romaink30/flutter_app_supabase.git
   cd flutter_app_supabase
   Flutter run ou vous pouvez le run directement sur votre émulateur ou un appareil
